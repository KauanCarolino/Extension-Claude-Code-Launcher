# Uma pasta de projeto

As conversas do Claude Code ficam indexadas pela pasta em que foram abertas, e a revisão guarda seus dados dentro dela, em `.claude/launcher-changes/`.

Essa pasta recebe um `.gitignore` próprio: nada dela vai para o repositório.

Workspaces com várias pastas funcionam: cada pasta tem o seu registro e as suas skills, regras e servidores MCP.
