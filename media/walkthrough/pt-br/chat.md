# Por que uma conversa nova

O Claude Code lê os hooks quando a conversa começa. Uma conversa que já estava aberta antes de você ativar o registro não grava nada.

Depois de ativar, abra uma conversa nova e peça uma edição qualquer. O arquivo aparece em **Mudanças** em seguida.

Se nada aparecer, abra o **Diagnóstico de captura** no painel: ele mostra se o hook rodou e em que etapa parou.
