# O chat vem da extensão oficial

O **Launcher for Claude Code** não tem chat próprio. Conversas, login, modelos e permissões são da extensão **Claude Code**, da Anthropic.

O launcher acrescenta:

- um atalho para abrir o chat na barra lateral ou em abas;
- a lista das conversas do projeto, para retomar qualquer uma;
- a revisão do que o Claude mudou em cada arquivo;
- abas para skills, regras, agentes e servidores MCP.

A instalação só acontece quando você clica em **Instalar Claude Code**.
